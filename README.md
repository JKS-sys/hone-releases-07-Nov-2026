<h1 align="center">Hone</h1>

<p align="center"><b>⭐ please star this repository</b></p>

Hone masters audio and video, upscales video and images, and makes speech, music, pictures and video with AI on your
own computer. A Mac app for Apple silicon. By Jagadeesh Kumar S.

## Install

```sh
pour install --cask hone
```

Or download **[Hone 1.1.20 for Apple silicon](https://github.com/JKS-sys/hone-releases-07-Nov-2026/releases/download/v1.1.20/Hone_1.1.20_aarch64.dmg)** (5.9 MB), open it and drag Hone to Applications.

Hone updates itself: Settings → About → Check for updates.
